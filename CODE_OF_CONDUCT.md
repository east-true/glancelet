# Code of Conduct

Glancelet is intended to be a welcoming, professional open-source project.

## Expected behavior

- Be respectful and constructive.
- Discuss ideas and code rather than attacking people.
- Assume good faith while remaining clear about technical disagreements.
- Respect privacy and do not publish another person's private information.
- Avoid harassment, discrimination, threats, or deliberately disruptive behavior.

## Enforcement

Project maintainers may edit or remove contributions, comments, issues, or other participation that violates these expectations, and may restrict participation when necessary to protect the project and its community.

For conduct concerns that should not be public, contact the maintainer through an appropriate private GitHub channel rather than opening a public issue.
