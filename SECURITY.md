# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting for this repository when available. Include the affected version or commit, impact, reproduction details, and any suggested mitigation. Do not include unrelated private workspace data, provider credentials, OAuth tokens, or personal information.

## Scope

Security-sensitive areas include credential storage, OAuth flows, source connectors, local database handling, IPC/Tauri command boundaries, and any path that could expose provider or workspace data.

Public bug reports should contain sanitized information only.
